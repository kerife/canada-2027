# Publicación en GitHub Pages

## Configuración

- Repositorio público: `kerife/canada-2027`.
- Rama de publicación: `main`.
- Carpeta: `/ (root)`.
- Settings → Pages → Build and deployment → Deploy from a branch.
- HTTPS mediante el dominio de GitHub Pages; sin dominio comprado.
- Dirección: https://kerife.github.io/canada-2027/

El sitio permanece disponible sin mantener encendida la computadora. No utiliza AWS ni infraestructura de servidor propia.

## Comprobación después de cada cambio

1. Revisar en Actions que el despliegue `pages build and deployment` termine correctamente.
2. Visitar el enlace público y confirmar que aparece la nueva versión.
3. Probar días 13, 14, 17, 18, 19, 20, 21 y 22; abrir detalles y comprobar fotografías.
4. Completar importes pendientes del presupuesto, borrar uno para confirmar que vuelve a total parcial y restablecer la propuesta.
5. Comprobar móvil y escritorio, sin desplazamiento horizontal inesperado.
6. Si aparece una versión anterior, recargar sin caché. Si aparece 404, comprobar rama, carpeta e `index.html` en la raíz.

## Alcance público

Los textos del itinerario, las fechas y las estimaciones mostradas en la página son públicos. No subir carpetas privadas, documentos de vuelos, comprobantes ni datos de acceso al actualizar este repositorio.

Los créditos identifican la procedencia de fotografías de terceros; no constituyen una concesión de derechos de reutilización.
